# Canciones de demostración / Demo songs

`kantor-demo-songs/` trae tres canciones **originales y sintéticas** (melodías de ondas senoidales, sin música de
terceros ni derechos) para probar Kantor sin tener una biblioteca UltraStar: una escala, un arpegio y un dueto.
Se dedican al dominio público (CC0). Cantalas o tarareálas con un micrófono para ver el puntaje.

`kantor-demo-songs/` has three **original, synthetic** songs (sine-wave melodies, no third-party music or rights) so you
can try Kantor without an UltraStar library: a scale, an arpeggio and a duet. They are dedicated to the public domain
(CC0). Sing or hum along with a microphone to see the score.

**Cómo usarlas / How to use them:** descargá `Kantor-demo-songs.zip`, descomprimilo, y en Kantor andá a
OPCIONES › BIBLIOTECA › *Agregar carpeta…* y elegí la carpeta descomprimida. /
Download `Kantor-demo-songs.zip`, unzip it, and in Kantor go to OPTIONS › LIBRARY › *Add folder…* and pick the unzipped folder.
